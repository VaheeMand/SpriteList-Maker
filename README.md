# SpriteList-Maker

SpriteList-Maker is an Android application designed to generate a spritesheet from a set of images. It allows you to import multiple files, adjust layout and scaling parameters, preview the result, and export the final spritesheet.

## Build From Source
1. Clone the repository:
   git clone https://github.com/VaheeMand/SpriteList-Maker.git
2. Open the project in Android Studio.
3. Ensure that the required Android SDK components are installed.
4. Build and run the `app` module using the built-in Gradle tools.

## Usage (Recommended)
Download the latest APK from the Releases page:  
https://github.com/VaheeMand/SpriteList-Maker/releases

After installing the APK:
- Launch the application.
- Import the images you want to include.
- Configure width, height, row count, and scaling mode.
- Preview the generated spritesheet.
- Export the final image to your device.

## Features
- Import multiple images  
- Configure sprite width and height  
- Set number of rows  
- Stretch / fit / crop scaling modes  
- Live preview of the spritesheet  
- Export to an image file  

## Notes
- Very large images or batches may cause memory issues on some devices.  
- UI is minimal and may be expanded in future versions.  
- Export options are basic and may be enhanced later.
